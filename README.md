# Simple Interest Calculator

A simple Bash-based calculator that computes simple interest from the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

When prompted, enter:
- Principal amount
- Annual rate of interest (percentage)
- Time period (years)

The script displays the calculated simple interest and total amount (principal + interest).

## Example

For principal `1000`, rate `5`, and time `2`:

- Simple Interest = 100
- Total Amount = 1100
